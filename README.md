# Simple Bot Trader

Fresh start. Installers are published as **GitHub Releases** (
`github.com/jpwhre/Simple-Bot-Trader/releases/latest` ):

- **Windows**: `SimpleBotTrader-Setup.exe`
- **macOS**: `SimpleBotTrader.dmg`
- **Linux / generic**: `simple-bot-trader.zip` (signed `curl|bash` bootstrap)

App source is staged per release; this repository root only carries the build
pipeline so nothing private ever touches the repo.
