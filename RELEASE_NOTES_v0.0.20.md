# Simple Bot Trader v0.0.20

Signed release. Install the native installer for your OS (double-click):

- **Windows**: `SimpleBotTrader-Setup.exe` — Installers & links on the Releases page (or `https://github.com/jpwhre/Simple-Bot-Trader/releases/latest/download/SimpleBotTrader-Setup.exe`)
- **macOS**: `SimpleBotTrader.dmg` (right-click → Open on first launch)
- **Linux (Debian/Ubuntu/Mint)**: `SimpleBotTrader.deb`
- **curl|bash / zip** (any OS, signed source):
```bash
curl -fsSL https://raw.githubusercontent.com/jpwhre/Simple-Bot-Trader/main/install.sh | bash
```

> First run on Windows shows SmartScreen `More info → Run anyway`; macOS shows
> `right-click → Open`. The app is free to use and has no paid code-signing cert —
> the sha256 + Ed25519 signature still blocks tampered/fraudulent installs.

> **Automatic bug reports require the OS-installer build. The curl|bash build
> keeps reports on your device — even after updates — until you install the OS
> version.**
